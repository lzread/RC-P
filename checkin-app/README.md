# Checkin App

This is a minimal cross-platform check-in application built with React Native and Expo. It supports Android and iOS platforms.

## Features
- Record check-in times with a simple button
- Display a list of previous check-ins

## Setup Instructions
1. Install [Node.js](https://nodejs.org/) and [Expo CLI](https://docs.expo.dev/get-started/installation/):
   ```
   npm install -g expo-cli
   ```
2. Navigate to the `checkin-app` directory:
   ```
   cd checkin-app
   ```
3. Install dependencies:
   ```
   npm install
   ```
4. Run the app on Android:
   ```
   npm run android
   ```
5. Run the app on iOS (requires macOS with Xcode installed):
   ```
   npm run ios
   ```

You can also start the development server with:
```
npm start
```
Then follow the instructions in the terminal to run on your device or emulator.
